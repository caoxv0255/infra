**踩过的坑**（记下来给未来的自己）：
1. Litellm `openai/MiniMax-M3` SDK 报 "LLM Provider NOT provided"——私有 model name 改用 `custom_openai/MiniMax-M3`

5. Aider 默认 whole-edit format 输出完整文件但不真写——改 `--edit-format diff` 才真用 SEARCH/REPLACE block 写

## 维护说明

- **如何算 round**：每次 a ider 重给一个 diff 或每次 chat completion 失败重试 = 1 round
- **如何算 manual**：你（人）看到了改的代码并手动改 = 1；看但没改 = 0
- **first_pass**：a ider 一次输出 / task 一次输出就过了 = 1 first_pass
- **推荐工具**：直接在 Obsidian / VSCode / vim 里编辑这个 .md 文件即可
- **不需要数据库**：一个 .md 文件比 SQLite 表更容易 grep、检索、复制
